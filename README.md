Student Details Task
A simple Student Management web application built using HTML and JavaScript.
Features

Add new student details (Name, Age, Gender, Course, Email)
Form validation with error messages
Display all students in a dynamic table
Delete student records from the table
Responsive and clean UI

Technologies Used

HTML5
CSS3
Vanilla JavaScript

How to Use

Fill in the student form (Name, Age, Gender, Course, Email)
Click the Save button
The student details will be added to the table below
Click the Delete button to remove any student record
